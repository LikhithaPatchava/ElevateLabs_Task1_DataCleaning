# Task 1: Data Cleaning and Preprocessing

## Objective

The objective of this task is to clean and preprocess a raw dataset by handling missing values, removing duplicates, standardizing formats, and preparing the data for analysis.

## Dataset Used

Netflix Movies and TV Shows Dataset

## Tools Used

* Python
* Pandas
* VS Code
* GitHub

## Steps Performed

1. Loaded the dataset using Pandas.
2. Checked for missing values.
3. Filled missing values in selected columns.
4. Removed duplicate records.
5. Standardized column names.
6. Converted date columns to datetime format.
7. Exported the cleaned dataset.

## Files Included

* `task1.py` - Python script for data cleaning
* `netflix_titles.csv` - Original dataset
* `cleaned_netflix_titles.csv` - Cleaned dataset
* `README.md` - Project documentation

## Outcome

Successfully cleaned and preprocessed the dataset, making it ready for further analysis and visualization.
